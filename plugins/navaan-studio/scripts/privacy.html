Privacy policy

NAVAAN STUDIO · BY NJLABS

Last updated 14 October 2026

NAVAAN Studio is a private production tool operated by NJLABS for a single owner. It helps the owner write, make and publish music and short videos to the owner's own YouTube and Instagram accounts. It is not offered to the public and has no other users.

What the app accesses

When the owner signs in with Google, the app asks for permission to use the YouTube API for the owner's own channels: to upload videos and Shorts, change their visibility and thumbnails, read the channel's own videos, comments and replies, and read the channel's analytics (views, watch time, audience and traffic reports).

How the data is used

The data is used only to do what the owner asks inside the app: publish the owner's content and show the owner's own statistics and recommendations. It is not sold, rented, shared with third parties, used for advertising, or used to train any model. Human access is limited to the owner.

Where the data lives

Sign-in tokens are kept in a secrets vault on the owner's own server and are never shown in the app or written to its logs. Song files, statistics and settings are stored on that server and in the owner's own cloud storage bucket. Nothing is sent to anyone else.

Google user data

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and revoking access

Data stays until the owner deletes it. The owner can revoke the app's access at any time at myaccount.google.com/permissions, which makes the stored tokens useless, and can delete the stored tokens from the app's Settings.

Changes

If this policy changes, the new version is published on this page with a new date.
